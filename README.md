# Manytask Gravity UI — галерея экранов

40 новых снимков: все **13 типов страниц**, диалоги, альтернативные представления и мобильная навигация. Снято в Chromium 29 сентября 2026 года на локальном стенде из коммита [`5ac13a9`](https://github.com/Teranikys/manytask/commit/5ac13a94d392fffcbf082095ae6e1c271ec67e76). Пользователи, оценки, секреты и токены на снимках — демонстрационные данные из `tests/ui_preview.py`.

[PR #1](https://github.com/Teranikys/manytask/pull/1) · [Как запустить такой же стенд](https://github.com/Teranikys/manytask/blob/5ac13a94d392fffcbf082095ae6e1c271ec67e76/REVIEWING.md) · [Метаданные снимков](manifest.json)

После запуска откройте `/__preview__/` и выберите роль, затем перейдите по пути в подписи. Для формы регистрации используйте отдельное окно без авторизации. Вариант входа через Yandex ID открывается через `/__preview__/sourcecraft`, завершение профиля — через `/__preview__/signup-finish/browsergallery`. Для варианта настроек SourceCraft сначала выберите административную роль, посетите `/__preview__/sourcecraft`, затем перейдите к форме курса.

Диалоги показаны до сохранения или подтверждения. Снимки 37–38 используют дополнительные демонстрационные данные, подставленные только в HTML ответа браузеру: они иллюстрируют поддерживаемые виды дедлайнов, которых нет в стандартном шаблоне стенда. Страницы внешних GitLab, SourceCraft и Yandex ID в галерею не входят.

Изображения хранятся в отдельной ветке с материалами ревью и не увеличивают diff кода PR.
